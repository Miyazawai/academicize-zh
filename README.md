# academicize-zh（学术化）

中文学术写作润色 skill。格式思路参照 [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)，但目标不同：Humanizer 管“像不像人写的”，这个管“学术写作有没有把话说过头、放错位置、前后不一致”。

核心取向是**声称强度校准**——学术润色最大的风险不是文字不好看，而是把相关写成因果、把计划写成完成、把样本结果写成普遍结论、以及为了让句子显得具体而补造数字。所以规则按优先级排列，第一条就是不许新增原文没有的材料。

## 内容

- 编辑约束与优先级（4 条，冲突时按序处理）
- 学科与文体差异（自然／工程／医学、社科、人文、学位论文、基金申请）
- 段落功能（摘要、引言、方法、结果、讨论、结论各自承担什么）
- 工作流程（6 步，声称校准排在结构之前）
- 输出与文件保护（公式、`\cite`、图表编号、参考文献、致谢与声明不动）
- 36 条模式，六组：
  - A. 声称强度与证据边界（1–8）
  - B. 学术空话与拔高（9–15）
  - C. 结构与信息组织（16–22）
  - D. 中文学术句法（23–29）
  - E. 术语、数字与格式（30–34）
  - F. 审稿与学术往来（35–36）
- 交付前核对（7 项）与完整示例

每条模式都是“规则 + 改写前 / 改写后 / 保留”三段式，“保留”标出不应下手的边界。

## 安装

```bash
mkdir -p ~/.claude/skills
git clone <你的仓库地址> ~/.claude/skills/academicize-zh
```

或手动把 `SKILL.md` 放进 agent 的 skills 目录。

## 使用

```
/academicize-zh 请把这段摘要润色成期刊投稿用的表达，目标刊物是中文核心
```

也可以直接说“帮我审一下方法部分的语言”“按学位论文的规范改这段讨论”“帮我回这条审稿意见”。

贴文本默认只给改写稿；要求改文件时只动散文正文。审阅模式只给意见，不写回。

## 注意

它不做代写：不会补数据、不会加引文、不会替你编后续计划。缺材料的地方会在正文之外提示你补。也不用于判断文本是否由 AI 生成，或用来规避检测。
